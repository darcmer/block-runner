# Block Runner

Піксельна гра-бігалка в стилі Minecraft: біжи за Стіва, збирай алмази, стрибай і присідай, уникай фантомів, відкривай скіни та улюбленців.

**Керування**
- Телефон: тап по екрану — стрибок, кнопка зліва внизу — присісти
- Комп'ютер: пробіл / ↑ — стрибок, S / ↓ — присісти

## Як викласти на GitHub Pages (щоб друг грав за посиланням)

1. Розпакуй цей zip на телефоні або комп'ютері.
2. На github.com створи новий репозиторій (New repository), наприклад `block-runner`, постав галочку **Public**.
3. Натисни **Add file → Upload files** і перетягни всі файли з папки (index.html, manifest.json, sw.js, обидві іконки, README.md). Сам zip завантажувати не треба. Натисни **Commit changes**.
4. Відкрий **Settings → Pages**. У розділі Build and deployment вибери **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисни Save.
5. Через 1–2 хвилини вгорі сторінки Pages з'явиться посилання виду `https://ТВІЙ-НІК.github.io/block-runner/`. Його й кидай другу.

На телефоні відкрий посилання в браузері і вибери **Додати на головний екран**: гра запуститься на весь екран і працюватиме без інтернету.

Оновити гру: у репозиторії відкрий index.html, натисни олівець або Upload files і заміни файл. Якщо гра на телефоні не оновилась, закрий її повністю і відкрий ще раз.
